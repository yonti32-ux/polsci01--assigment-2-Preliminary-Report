# Typography and BiDi reviewer

Read-only independent review of the lead's newly rebuilt PDF and its rendered pages. Read the PDF skill. Inspect Hebrew/English direction, punctuation and ranges, heading orphans, caption placement, table readability, borders, footer collisions, floats, and the final conclusion box. Use actual PDF page numbers and separately note printed page labels. Check text extraction as well as visible glyphs. Do not edit sources. Write specific findings and review coverage to typography-review.md in this folder. The lead author makes corrections.
