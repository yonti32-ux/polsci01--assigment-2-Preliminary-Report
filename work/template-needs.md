# מה התבנית (template.cls) צריכה לספק

הפרקים כתובים בלי שום עיצוב. כל פקודה כאן חייבת להיות מוגדרת בתבנית, אחרת הקומפילציה תיכשל.
כשפרק חדש משתמש בפקודה חדשה – מוסיפים אותה לרשימה.

| פקודה | מה היא עושה | בשימוש בפרק |
|---|---|---|
| `\en{...}` | טקסט באנגלית בתוך עברית (כיוון LTR, גופן אנגלי) | 1 |
| `\LR{...}` | קטע משמאל לימין – בעיקר טווחי שנים כמו `\LR{1776--1789}`, כדי שלא יתהפכו | 1 |
| `keybox` (סביבה עם כותרת) | תיבה מודגשת: `\begin{keybox}{כותרת} ... \end{keybox}` | 1 |
| `\chapter`, `\section`, `\label`, `\ref` | מבנה ומספור רגילים | 1 |
| `\cite{...}` | הפניה למקור מתוך `references.bib` (biblatex + biber); גם כמה מפתחות יחד: `\cite{a,b}` | 1, 2, 3 |
| `booktabs` (`\toprule`, `\midrule`, `\bottomrule`) | קווים בטבלאות. העיצוב הסופי של הטבלאות – בתבנית | 2 |
| `\multicolumn` | תא שמתפרס על כמה עמודות | 2 |
| `tikz` + ספריות `positioning`, `arrows.meta` | איורים בקוד (`figures/*.tex`) | 2, 3 |
| `\checkmark` (חבילת `amssymb`) | סימן ✓ במטריצת הספרות | 3 |
| `\paragraph{...}` | כותרת פסקה (רמה רביעית, בלי מספור) | 3 |
| `\subsection*{...}` | תת-סעיף בלי מספור | 2, 3 |
| `\includegraphics` (חבילת `graphicx`) | גרפים מ-Python (`figures/*.pdf`) | 4 |
| צבעים `accent`, `accentlight` | צבע ראשי וצבע רקע בהיר לאיורים. התבנית קובעת אותם; לאיורים יש ערכי ברירת מחדל זמניים. **אותם צבעים מוגדרים גם ב-`code/make_figures.py`** – אם משנים, משנים בשני המקומות | 2, 3, 4 |


## בקשות עיצוב

- התיבה `keybox` לא נחתכת באמצע עמוד.
- כותרת סעיף לא נשארת לבד בתחתית עמוד.
- רשימת המקורות: הרשומות באנגלית בכיוון LTR.

## חלקים מקדמיים (מוגדרים ב-`main.tex`)

| פקודה | מה היא עושה |
|---|---|
| `\reporttitle{עברית}{English}` | כותרת הדוח בשתי השפות |
| `\reportsubtitle{עברית}{English}` | כותרת משנה בשתי השפות |
| `\reporttype{עברית}{English}` | "דוח מכין / Preliminary Report" |
| `\institution{עברית}{English}`, `\course{...}`, `\semester{...}` | פרטי המוסד והקורס |
| `\authors{א \and ב}`, `\lecturer{...}`, `\submissiondate{...}` | פרטי הצוות, המרצה ותאריך ההגשה |
| `\makecoverpage` | מדפיס את השער: בלי מספר עמוד, עם מסגרת, כותרת בשתי שפות וסימן זכויות יוצרים. **בלי לוגו מהאינטרנט** – רק איור מקורי ב-TikZ |
| `\frontmatter`, `\mainmatter` | מספור נפרד: אותיות (א, ב, ג) לחלקים המקדמיים, ספרות לגוף הדוח |
| `executivesummary` (סביבה) | תקציר המנהלים, עם כותרת "תקציר מנהלים" |
| `\keywords{...}` | שורת מילות מפתח מתחת לתקציר |
| `\listoffigures`, `\listoftables` | רשימות איורים וטבלאות אוטומטיות |
| `abbreviations` (סביבה) + `\abbr{קיצור}{פירוש}` | רשימת קיצורים ומונחים, בטבלה של שתי עמודות |

## דרישה לגופן העברי

הפרקים משתמשים בסימני פיסוק עבריים אמיתיים: **מקף עברי** (־, למשל "וורד־פרקינס"), **גרשיים** (״, למשל "ד״ר", "סה״כ") ו**גרש** (׳, למשל "סמסטר א׳").
הגופן שנבחר לתבנית חייב לכלול אותם. גופנים כמו David CLM, Frank Ruehl CLM או SBL Hebrew כוללים אותם; כדאי לבדוק בקומפילציה הראשונה שהם לא מופיעים כריבוע ריק או כסימן אחר.


## סטטוס מימוש 21.11.2026

הפקודות והסביבות ברשימה מומשו ב־`template.cls`. הפלטה המשותפת היא `accent=#820000`, `secondary=#330f53`, `cream=#fcfbf4`; הצבע `accentlight` הוא כינוי לקרם. גם צבעי הגרפים ב־Python עודכנו. `build.ps1` מבצע את ארבע הרצות הבנייה; בדיקת התוכן והמקורות היא שלב נפרד שטרם הושלם.


## עדכון בעקבות הביקורת והחלטת הגופן

הגופנים מוחזקים בתיקיית `fonts/` עם רישיונות OFL: גוף Noto Sans Hebrew ו־Noto Sans, כותרות עבריות Condensed Bold ברוחב 75%. אין תלות ב־David ואין FakeSlant. התבנית מודדת את רוחב הטבלה בלי להקטין טקסט, ו־`build.ps1` עוצר בטבלה רחבה. פרמטרי ה־floats עודכנו; חיפוש והעתקת נ ותווי הפיסוק נבדקים בפלט שנבנה מחדש. הביקורת המקורית נשמרה כמות שהיא; מצב הטיפול מופיע ב־`review-followup.md`.


`reportconstraints`: רשימת אילוצים עם ריווח מצומצם בין פריטים, ללא הקטנת גופן הגוף. נועדה לשמור את ארבעת האילוצים בפרק 2 יחד לאחר עדכון שאלת המחקר.
